Presentación y Estructura

El presente portafolio digital tiene como finalidad documentar, organizar y exponer las evidencias académicas desarrolladas a lo largo del curso de Seguridad Informática. Este sitio web opera como un repositorio técnico estructurado que recopila de manera cronológica las actividades conceptuales, las prácticas de laboratorio y los análisis de infraestructura desplegados durante el semestre académico.

El entorno está diseñado bajo una división modular correspondiente a las distintas etapas del programa de estudio. Cada sección agrupa evidencias específicas enfocadas en consolidar competencias esenciales en la materia, tales como el análisis estructurado de vulnerabilidades, la evaluación cualitativa de riesgos tecnológicos y la correcta implementación de controles informáticos.

Propósito Académico

El objetivo primordial radica en demostrar la asimilación y el desarrollo de competencias técnicas avanzadas en seguridad de la información. A través de este compendio de trabajos prácticos, se evidencia la capacidad para evaluar entornos digitales bajo los pilares fundamentales de la ciberseguridad: garantizar la confidencialidad de los datos, resguardar la integridad del sistema frente a modificaciones no autorizadas y asegurar la disponibilidad continua de los recursos tecnológicos esenciales.

Perfil Profesional

Estudiante de Ingeniería en Tecnologías de la Información con especial enfoque hacia la seguridad informática, el análisis proactivo de vulnerabilidades y la optimización de esquemas de protección para infraestructuras tecnológicas críticas.

Documentación Técnica del Sitio

  • Lenguaje principal: HTML5 / Estructura Semántica
  • Diseño y Maquetación: CSS3 (Adaptación sobre plantilla Telephasic de HTML5 UP)
  • Despliegue y Alojamiento: GitHub Pages / Cloudflare Pages (Arquitectura Estática)
  • Control de versiones: Git para el seguimiento de código
  • Procesamiento de contacto: API externa vía Formspree

El sitio web aprovecha las ventajas de un esquema estático de alto rendimiento basado puramente en HTML5 y hojas de estilo CSS3. La navegación se administra fluidamente mediante un menú jerárquico integrado que mapea directamente los recursos y evidencias clasificados por parcial académico. Al prescindir por completo de motores de bases de datos tradicionales o procesamiento pesado en el backend, la plataforma garantiza una carga óptima, un consumo mínimo de recursos y una compatibilidad multiplataforma impecable.
